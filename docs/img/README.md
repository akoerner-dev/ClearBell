# Bilder

Hier gehören die im Haupt-README verlinkten Bilder rein. Erwartete Dateinamen:

| Datei | Inhalt |
|---|---|
| `hero.jpg`       | Bestes Gesamtbild (oben im README; dient zugleich als „Außeneinheit PCB") |
| `pcb_innen.jpg`  | Platine Inneneinheit |
| `prototyp.jpg`   | Prototyp montiert / im Betrieb |
| `schaltplan.jpg` | Aussagekräftiger Schaltplan-Ausschnitt |

Tipp: `.jpg` für Fotos, `.png` für Screenshots/Renderings. Wenn du ein anderes
Format oder andere Namen nutzt, die Verweise im Haupt-`README.md` entsprechend
anpassen. Ein KiCad-3D-Render bekommst du über *Ansicht → 3D-Betrachter →
Bild exportieren*.
